# Selection audit 2026-09-10

This directory contains small, publishable evidence tables for the sample-selection audit.

- `mass_selected_kappa_frames.csv`: new computation for all 260 stellar-mass-selected subhaloes.
- `candidate_review.csv`: 33 paper objects plus the currently known disputed or added candidates.
- `legacy_velocity_crossers_lensing.csv`: preserved historical output; its mass deposition used
  single-pixel rounding despite the CIC label.
- `legacy_candidate_shape_summary.csv`: historical shape diagnostics for the ten velocity crossers.
- `legacy_paper33_kappa.csv`: source used to transcribe the paper parent membership.
- `legacy_paper33_shape_summary.csv`: historical shape diagnostics for those 33 systems.
- `manifest.json`: definitions and SHA256 provenance.

The TNG particle data are not redistributed. The legacy tables are evidence, not current method defaults.
See [scientific conventions](../../../docs/CONVENTIONS.md) for interpretation and open decisions.
